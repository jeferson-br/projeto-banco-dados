AutoMoto Peças Central

Projeto de Banco de Dados

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Banco de Dados, com o objetivo de criar um banco de dados para gerenciamento de uma loja de autopeças.

Objetivo do Projeto

O objetivo é desenvolver um banco de dados capaz de organizar e gerenciar informações de clientes, funcionários, fornecedores, produtos, categorias, vendas, itens vendidos e pagamentos, facilitando o controle das operações da empresa.

Sobre o Sistema

O banco de dados foi projetado para representar o funcionamento de uma loja de peças automotivas e motociclísticas, permitindo o registro de clientes, controle de produtos, acompanhamento de vendas e gerenciamento de pagamentos.

Entidades do Banco de Dados

  • Cliente
  • Funcionário
  • Fornecedor
  • Categoria
  • Produto
  • Venda
  • Item_Venda
  • Pagamento

Relacionamentos

O banco de dados possui relacionamentos entre as entidades, permitindo associar clientes às vendas, funcionários às vendas, fornecedores aos produtos, categorias aos produtos e vendas aos seus respectivos itens e pagamentos.

Tecnologias Utilizadas

  • MySQL
  • SQL
  • Modelagem de Banco de Dados

Conteúdos Desenvolvidos

  • Criação do banco de dados
  • Criação das tabelas
  • Definição de chaves primárias e estrangeiras
  • Inserção de dados
  • Consultas SQL
  • Criação de Views
