Sobre o projeto

Uma solução de banco de dados para representar as operações de uma loja de autopeças de forma organizada e estruturada.

O AutoMoto Peças Central é um projeto acadêmico que simula a estrutura de dados de uma empresa do segmento de autopeças.

O banco foi desenvolvido para armazenar informações relacionadas a clientes, funcionários, fornecedores, categorias, produtos, vendas, itens vendidos e pagamentos.

A proposta é aplicar conceitos de banco de dados relacionais, permitindo o registro, relacionamento, consulta e organização dos dados de uma empresa.

Propósito do sistema

Centralizar os dados da loja em um banco relacional, facilitando consultas, controle das informações e análise das operações comerciais.

Estrutura relacional

Modelagem do banco de dados

O banco de dados possui oito entidades principais, conectadas por relacionamentos que representam as operações da loja.

Cliente

Dados pessoais, contato e cidade dos clientes.

Funcionário

Informações dos funcionários e seus cargos.

Fornecedor

Dados comerciais e informações de contato.

Categoria

Classificação e organização dos produtos.

Produto

Produtos, preços, estoque e fornecedor.

Venda

Registro das vendas realizadas pela loja.

Item_Venda

Produtos, quantidades e valores por venda.

Pagamento

Valores, métodos, parcelas e status de pagamento.


Relacionamentos principais

Cliente → Venda
Um cliente pode realizar várias vendas.
Funcionário → Venda
Um funcionário pode registrar várias vendas.
Fornecedor → Produto
Um fornecedor pode fornecer vários produtos.
Categoria → Produto
Uma categoria pode possuir vários produtos.
Venda → Item_Venda
Uma venda pode possuir vários itens.
Produto → Item_Venda
Um produto pode aparecer em diferentes vendas.
Venda → Pagamento
Uma venda pode possuir registros de pagamento.

Instalação

Como executar

Siga os passos para executar o banco de dados em seu ambiente local.

1

Instale o MySQL

Instale o MySQL Server 8 e o MySQL Workbench para administrar e executar os comandos SQL.

2

Abra o arquivo SQL

Abra o MySQL Workbench e acesse File → Open SQL Script. Selecione o arquivo automoto_pecas_central.sql.

3

Execute o script

Execute o script para criar o banco de dados, as tabelas, os relacionamentos e os registros de exemplo.

4

Explore as consultas

Após a execução, utilize as consultas SQL disponibilizadas para explorar os dados, analisar vendas e verificar informações.
